# Rahul Singh — Portfolio

A modern, premium developer portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🛠️ Tech Stack

- **React 18** + **TypeScript**
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **React Type Animation** for typing effect
- **React Intersection Observer** for scroll animations
- **Vite** as build tool

## ✏️ Customization

1. Update personal info in each section component
2. Add your resume as `public/resume.pdf`
3. Update social links and contact details in `Contact.tsx` and `Footer.tsx`
4. Update GitHub links in `Projects.tsx`

## 📦 Deployment

Deploy easily to Vercel, Netlify, or GitHub Pages:

```bash
npm run build
# Upload dist/ folder
```
